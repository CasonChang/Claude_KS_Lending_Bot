## 額度顯示的建議口徑

- 上限：Zeabur 載入的 `LENDING_MAX_USD`／`LENDING_MAX_USDT`；留白不限制，0 停止新增。
- 已承諾本金：放貸＋掛單；引擎還會保守納入 API 未列出但錢包已預留的資金。
- 可新增金額：可用餘額與總額度剩餘兩者的較小值；實際仍受最小掛單額及策略條件限制。
- 可用中保留：可用餘額減上述金額，主要是因總上限而不續掛的錢；不是已完成提領。
- 等待還款：當放貸本金已高於上限，呈現超出本金及放貸天期，但不能保證精確返還日期。

額度、保留資金原因與等待還款欄位尚未加入網頁／資料庫；現有可用餘額卡片不會假設所有可用資金都是準備出金。
